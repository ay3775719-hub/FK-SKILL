# 人像参考图提示词

一个个人使用的完整 skill，保留原框架，不拆分。

上传第 1 张主图和至少 1 张姿势参考图后，说：

> 使用人像参考图提示词 skill，按我的框架出提示词，场景是咖啡馆，只输出提示词。

也可调用 `/portrait-reference-prompt-skill`。

默认交付前置自检和绑定表，再交付与姿势图数量相等的独立 3:4 竖版照片正向提示词及逐张固定负面词；不自动生成图片。
没有参考图时先指出缺图。主图非拼接图时按实际可见内容识别，不强套分区。

## 可选前置：先建角色定妆板

如果还没有统一的角色主图，可以先分别给两张图：**人物参考图**（锁脸、发型、妆容）和**服装参考图**
（锁服装、配饰、鞋）。助手会先确认两张图分工，再用 5.0 Pro 生成一张 9:16 角色定妆四宫格参考板
（正脸、侧脸、无头正面服装、背面全身，模板见 `assets/character-board-prompt.txt`）。
这张四宫格随后作为后续姿势复刻的主参考图（第 1 张），姿势图从第 2 张起。
直接说：“人物图锁脸、服装图换装，先给我出定妆四宫格”。

## 开始前先上传什么

1. **主参考图放第一张：** 建议将清晰大头特写与全身穿搭放在一张拼接图中，脸妆要清楚，全身尽量包含鞋包及配饰。单张照片能看清脸和穿搭也可以，不强制拼图。
2. **后面放姿势图，至少一张：** 参考动作、神态、拍法，以及该图的场景背景和环境光线；不采用其人物长相、妆容、发型或穿搭。给多少张姿势图就出多少条，不延伸、不凑数。
3. **可选：** 统一指定场景（覆盖所有姿势图背景）、道具、禁用元素或指定妆容。不指定场景时，每张照片的场景来自其对应姿势参考图。

脸部和穿搭图也可以分开上传，但请标明“脸妆主图”和“穿搭主图”，以免被误作姿势图。
直接说“使用这个 skill”还没上传图片时，助手会先给准备清单；已上传齐全时直接执行，缺什么只补问什么。

## 主要规则

- 妆容与肤色默认按主图实际细节；“冷艳女团妆”只作为可选预设。
- 来源分工与规则放入自检，正向词改成具体画面。
- 关键姿势动作（手部、头部、身体、腿部）具体准确并前置；俯拍、手部、歪头、坐姿为重点核对项。
- 主图可见配饰和首饰在每张中固定出现，不增不减。
- 固定负面词使用自然语言“画面中不要出现……”，每张原样附带一次。
- 生图后逐张回读对照绑定表做后验检查，不达标针对性重生成，每张最多重试 2 次。
- 批量生成后按编号保存到项目目录。

读取 `references/framework.md` 查看完整执行版；原文在 `assets/original-framework.txt`。

## 检查与修改

日常无需命令。可直接告诉助手：“修改这个 skill：……”并描述实际问题。
若将输出存为 Markdown，运行 `python scripts/check_output.py 输出.md --count <姿势图数量>` 检查数量、格式与负面词。
需要记录维护建议时，运行 `python scripts/evolve.py --correct "具体问题"`。
格式检查不能证明识图正确或生图身份一致；详见 `VERIFICATION.md` 的实际验证范围。
