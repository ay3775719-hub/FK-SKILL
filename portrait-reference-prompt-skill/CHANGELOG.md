# 变更记录

## 1.5.0 — 2026-10-19

在流程最前面新增「角色建档（定妆四宫格）」可选前置：

1. 用户提供人物参考图＋服装参考图、要求先换装建档时，先询问并确认两张图分工（人物图锁脸/发型/妆容，
   服装图锁服装/配饰/鞋），再生成 9:16 角色定妆四宫格参考板（左上正脸、右上侧脸、左下无头正面服装、
   右下背面全身）。
2. 四宫格固定使用 seedream_5.0_pro；模板沉淀为 `assets/character-board-prompt.txt`，含填空区、
   调用约定、审核预处理与逐格核对清单。
3. 该四宫格完成后即作为后续姿势复刻流程的主参考图（第 1 张），姿势图从第 2 张起编号。
4. 实测经验固化：人物图衣着暴露会触发输入审核，先裁成面部大头照再传入并改用中性服装表述；
   左下“无头”是高发失败点，残留下巴可用顶部裁切重拼修正（见 Gotchas 与模板清单）。

SKILL.md（frontmatter、Trigger、前置节、上传引导分支、执行顺序、输出边界、Gotchas）、
framework.md（第 16 条）同步更新，版本升至 1.5.0。

## 1.4.0 — 2026-10-19

基于10张图实战复盘，新增五项改进：

1. 生图后验检查（强制环节）：每张生成后回读图片，对照绑定表逐项核对关键姿势、头部角度、景别、机位、场景、配饰和人物外观，不达标针对性重生成，每张最多重试2次。新增"十四-A、生图后验检查规则"章节。
2. 姿势细节强化：手部位置、头部角度、身体朝向、腿部关系、重心等关键动作具体且前置；俯拍、手部、歪头、坐姿列为高发错误点重点核对。
3. 负面词适配：固定负面词从 --no 前缀改写为"画面中不要出现……"自然语言否定描述；原始 --no 版本备份为 negative-prompt-legacy-no.txt。
4. 配饰锁定：主图可见首饰配饰在每张中固定出现，不增不减，提示词人物统一段列出并在后验检查中确认。
5. 生图自动存档：批量生成完成后按编号保存到项目输出目录，云端链接同时交付。

SKILL.md、framework.md、negative-prompt.txt 同步更新，版本升至 1.4.0。

## 1.3.0 — 2026-09-30

用户要求取消"不足十张自然延伸补齐"机制：给多少张姿势参考图就出多少条提示词，不延伸、不凑数。
SKILL.md 与 framework.md 中所有"默认十条/十张""不足延伸"表述统一改为"输出条数等于姿势参考图数量"。
原第五节"参考图不足十张时的延伸规则"整节替换为"输出数量规则（不延伸）"，明确所有输出均为复刻，不存在延伸图。
绑定表从固定十行模板改为按实际姿势图数量动态逐行列出，类型全部为"复刻"。
视线分配从"4 直视 : 6 非直视"改为"直视与非直视尽量平衡，不覆盖复刻图视线"。
总控指令同步去掉延伸补足段落，改为"有多少张出多少条，不延伸、不凑数"。

## 1.2.0 — 2026-09-30

用户反馈生图时只传主图凭文字描述背景会导致模型编造场景，与姿势参考图真实环境不符。
生图流程改为双参考图传入：第一张主图锁定人物脸、妆、发、穿搭、身材；第二张对应姿势图提供真实背景环境、建筑空间、道具和光线。
提示词中必须明确写"人物外观完全参考第一张参考图""背景环境完全保留第二张参考图的真实场景"。
不再裁剪或模糊姿势图（需要完整图片保留真实背景），去身份化依靠提示词分工声明而非修改原图。
"姿势图去身份化规则"整节重写：从"优先只传主图+文字控制"改为"双参考图+提示词明确分工"。
框架顶部已批准补充新增第 10 条（生图双参考图规则）。

## 1.1.0 — 2026-09-30

用户要求姿势参考图（第 2 张起）除参考姿势外，同时参考场景背景。
取消"整组十张同一核心主场景"规则：每张照片的场景、环境元素和光线氛围来自其对应姿势参考图，用户统一指定场景时覆盖全部。
人物外观（脸、妆、发、穿搭、身材）仍只来自主图，十张统一，绝不从姿势图继承。
延伸图场景从已有姿势图中选取最适配的一个，不凭空编造无关场景。
色彩规则调整：人物色彩十张统一，背景色彩与光线随各场景自然变化。
绑定表增加"场景来源"字段，自检区"最终场景"改为"各张场景来源"。
check_output.py 校验关键词同步更新。
