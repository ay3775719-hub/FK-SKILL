## 二、姿势图去身份化规则

生图时同时传入主参考图和对应姿势参考图：主图锁定人物身份，姿势图提供真实背景环境。
为避免姿势图人物的脸、妆容、发型和穿搭干扰生成结果，必须执行以下原则：

### 双参考图分工（默认方式）

正式生图时，同时上传两张参考图：
- 第一张：主参考图——人物身份、五官、脸型、骨相、妆容、发型、穿搭、身材的唯一来源。
- 第二张：对应姿势参考图——真实背景环境、建筑空间、道具、光线氛围的来源；同时提供姿势、构图、景别、机位、焦段参考。

提示词中必须明确写出分工：
- "人物外观完全参考第一张参考图"
- "背景环境完全保留第二张参考图的真实场景"
- 再描述本张具体姿势、神态、构图和机位。

不要裁剪、模糊或遮挡姿势图——需要完整图片来保留真实背景。去身份化依靠提示词明确分工，而非修改原图。

### 提示词中必须声明

人物身份、面部特征、发型、妆容、穿搭和气质以主参考图为唯一来源；
姿势参考图仅用于动作、构图、景别、机位、焦段和场景背景参考，
不提供人物脸型、五官、骨相、眉形、眼妆、唇色、发型和穿搭。

## 五、输出数量规则（不延伸）

输出条数等于姿势参考图数量，有多少张姿势图就出多少条独立照片提示词，不延伸、不凑数。

### 绑定原则：

每张照片严格一一绑定对应姿势参考图（姿势 + 场景同时绑定）。
不存在"延伸图"，所有输出均为对已有姿势参考图的复刻。
用户明确指定输出数量且少于姿势图数量时，按指定数量选取前 N 张，并在绑定说明中注明采用范围。
用户明确指定输出数量且多于姿势图数量时，仍按实际姿势图数量输出，并说明"姿势图不足，不延伸"。

### 必须保持：

人物身份仍然只来自主参考图对应区域。
脸型、五官、骨相、妆容、发型、穿搭不变。
每张照片的场景来自其对应姿势参考图的可见环境。
机位和焦段忠实复刻对应姿势图。
每张仍然是单张独立照片。

### 禁止：

为凑数量随机编造完全无关姿势。
凭空编造没有任何姿势图依据的场景。
把同一张参考图机械复制成多张完全重复画面。
从姿势图继承脸型、五官、骨相、妆容、发型或穿搭。

一句话原则：

**一张姿势图绑定一张照片（姿势+场景）；给多少张出多少条，不延伸、不凑数。**

## 七、六项复刻规则

每张照片必须复刻对应参考图的六项内容：

### 1）姿势

复刻身体方向、肩膀方向、手部位置、腿部关系、重心、脚部朝向、头部角度、站姿 / 坐姿 / 靠姿 / 行走姿态。

### 2）神态

复刻眼神方向、嘴角状态、眉眼情绪、放空感、抓拍感、清冷 / 温柔 / 慵懒 / 松弛等气质。

神态复刻不包括脸型、骨相、鼻型、下颌线、面部结构和妆容。

### 3）构图

复刻人物位置、人物占比、留白方向、画面疏密、人物与边缘距离。

### 4）景别

复刻特写、近景、半身、中景、全身、远景环境人像。

## 十四-A、生图后验检查规则

每张图片生成后，必须实际回读图片，对照绑定表逐项核对，不达标不得交付。

### 核对清单（逐项标注通过/不通过）：

1. **关键姿势**：身体方向、肩部方向、手部位置、腿部关系、重心、脚部朝向是否与姿势图一致
2. **头部角度**：头部朝向、转动角度、是否侧脸/回头/歪头是否到位
3. **神态与视线**：眼神方向、表情是否与姿势图一致
4. **景别**：特写/近景/半身/中景/全身/远景是否正确
5. **机位**：俯拍/平视/仰拍、正面/侧面、拍摄距离是否正确
6. **场景背景**：环境、建筑空间、道具、光线是否保留了姿势图真实场景
7. **人物外观**：脸型、五官、妆容、发型是否与主图一致
8. **配饰**：项链、手链、戒指、包袋挂件等是否出现且与主图一致
9. **独立成片**：是否为单张照片，无拼图合集多人物

### 重点核对项（高发错误）：

- 俯拍图：机位是否为正上方，手部/膝盖位置是否正确
- 手部动作：手指数量、手部位置、持物方式是否正确
- 歪头/前倾：身体倾斜幅度和头部角度是否到位
- 坐姿：腿部关系、重心、手部支撑位置是否正确

### 不达标处理：

指出具体偏差项（例如"手部位置偏了，应在画面上方而非身前"），针对性调整提示词后重新生成。
每张最多重试 2 次；重试后仍不达标，如实说明偏差，保留最接近的版本，由用户决定是否接受。
全部核对通过后再统一交付，不得生成后直接交付。
